# Network Toolkit PRO

**A portable field toolkit for Windows network technicians.**
Switch network settings, monitor connections, and discover devices — from a single `.exe`, no installation.

## What it does

- **Network profiles** — save several sets of settings (IP, subnet mask, gateway, DNS) under names and switch between them in one click.
- **Connection Monitor** — ping several targets once a second and record a timestamped CSV log, so a dropped link can be pinned to the layer at fault with objective evidence. ICMP only; it never opens a session to your equipment.
- **Device discovery (ARP)** — sweep the local network and list every device with its address, MAC and maker — including one whose address you did not know.
- **Bilingual (English / Arabic)**, follows your Windows language and theme, and fits small laptop screens.

## Download

Get the latest release from the [**Releases**](https://github.com/qalbhamad/network-toolkit-pro/releases/latest) page.
The ZIP contains the program, an illustrated PDF guide, and a README.

## Requirements

- Windows 11, 10, or 8.1 (the required .NET Framework is already built in)
- Administrator permission at launch (changing IP settings needs it)

## Updates

The program can check here for newer versions from **Help → Check for Updates**. It only tells you and offers to open the download page — it never installs anything by itself.

# Network Toolkit PRO — عربي

**صندوق أدوات محمول لفنّيي الشبكات على ويندوز.**
تبديل إعدادات الشبكة، ومراقبة الاتصال، واكتشاف الأجهزة — من ملف `.exe` واحد، بلا تثبيت.

## ماذا يفعل

- **ملفات تعريف الشبكة** — احفظ عدة مجموعات إعدادات (IP، القناع، البوابة، DNS) بأسماء وبدّل بينها بنقرة.
- **مراقب الاتصال** — ping لعدة أهداف كل ثانية مع سجل CSV بطابع زمني، فيمكن عزل موضع انقطاع الرابط بدليل موضوعي. ICMP فقط، ولا يفتح أي اتصال بمعداتك.
- **اكتشاف الأجهزة (ARP)** — مسح الشبكة المحلية وسرد كل جهاز بعنوانه و MAC وصانعه، حتى ما لا تعرف عنوانه.
- **ثنائي اللغة**، يتبع لغة ويندوز ومظهره، ويناسب الشاشات الصغيرة.
